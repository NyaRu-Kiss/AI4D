# 4.3 Knowledge Base

标号 ②。本节把知识库笔记里已经写过的知识生命周期，和腾讯云知识引擎 / ADP 的公开链路，收成通用的知识层做法。产品细节以各自主页当时的文档为准；笔记里的腾讯链路引用的是 2026-10-02 整理的公开文档。

## 4.3.1 知识、记忆和会话不是同一层

| 层 | 保存什么 | 谁可以改 | 进入模型的方式 |
| --- | --- | --- | --- |
| 组织知识 | 制度、手册、接口说明、已接受的 ADR | 所有者评审后发布 | 检索，带版本和引用 |
| 会话 | 这一次任务的消息和工具结果 | 任务结束可过期 | 当前上下文 |
| 工作记忆 | 当前计划、已完成步骤 | 任务状态机 | 只注入后续步骤需要的字段 |
| 长期偏好或项目记忆 | 用户明确要求记住的偏好、已确认的项目决定 | 带同意、过期和删除 | 按权限召回，不把整段历史写入 |
| 本体候选 | 新别名、新关系 | 审核后才进入 T-Box 或术语表 | 未发布前不作为正式事实 |

知识库笔记《腾讯智能体记忆管理与上下文工程》强调：ADP 公开的 History、Knowledge 和任务结构支撑上下文，但不能据此断言存在一个统一的长期记忆 API。工程上把记忆适配器单独做，避免把检索结果叫做“用户记忆”。TencentDB Agent Memory 是公开的开源实现，把对话、原子记忆、场景记忆和长期画像分开，并进一步沉淀 Skill、Wiki 和 CodeGraph。它可以作为分层案例，不等于任何一个商业产品的内部实现。

## 4.3.2 方法论

知识从进入到退出：

```text
来源登记 → 解析 → 清洗 → 切分 → 元数据 → 审核发布 → 索引
→ 线上引用 → 到期或被替代 → 切片、向量和引用一起失效
```

每份文档登记：所有者、分类、生效时间、失效时间、租户、可否用于模型训练、原文位置。没有这些字段的文件留在收件区，不进入可检索集合。

切分要保留能够引用的结构：标题、章节、页码或条款号。只按固定字数切开，回答时无法指出依据。父子块可以同时存在：小块用于召回，父块用于交给模型的上下文。具体策略用真实问题集比较，不预设一种切分适合所有制度文件。

权限过滤使用和业务系统一致的身份。切片上的访问标签必须在召回前生效。

审核发布和业务代码发布类似：草稿、已接受、已替代。已替代的版本默认不可被检索，除非问题明确要求历史版本。

## 4.3.3 笔记中的一条可运行链路

知识库对腾讯云公开能力的整理把知识问答拆成可观测步骤：上传或接入、解析、拆分、Embedding、向量召回、Rerank、注入 Agent、输出答案和引用、记录成本和错误。

笔记区分两层产品：

| 产品 | 笔记中的定位 | 适合 |
| --- | --- | --- |
| ADP 知识库 | Agent 应用内的知识 | 先把带引用的问答跑通 |
| 知识引擎原子能力 | 解析、拆分、Embedding、多轮改写、Rerank 等 API | 平台团队自己编排 |

笔记要求上线前自行验证：文件格式和大小、增量与删除、各步骤能否单独调用、是否返回出处和更新时间、租户权限、内容会不会用于训练、计费口径。这些验证项对任何托管知识库都适用，不限于一家云厂商。

引用结构在笔记中按 ADP 对话接口的公开名称区分文档片段、问答和图谱引用。字段以对应版本的 API 为准。

## 4.3.4 AI Coding 技巧和注意点

技巧：

- 仓库里的规范、ADR 和接口说明在被接受之后再入库，并带 Git 提交标识。Coding Agent 检索这些已接受文本，不检索未合并的草稿。
- 给索引管道一组黄金文件：正常 PDF、扫描件、双栏、表格、空文件。解析失败要计数。
- 用模型为切片生成标题草稿，人抽查标题是否歪曲条款。

注意点：

- 把整个代码仓库嵌入知识库，会让过期实现和密钥样例变成“依据”。代码知识只收录标记过的模块说明和现行接口。
- 自动摘要若替代原文进入索引，回答会引用摘要里的错句。摘要可以辅助召回，引用必须回到原文切片。
- 增量更新如果只追加不删除，旧制度会和新制度同时被召回。发布新版本时退役旧切片。

## 4.3.5 工具如何接入

解析器输出统一的中间文档：块、标题层级、表格、页码、原文哈希。后面的切分和嵌入不依赖某一个解析器的私有对象。托管知识库如果不能导出切片和引用标识，就难以迁走，也不能做独立评测。

工具对照（解析器、切分框架、托管知识库）在 `docs/reference/tools.md` 按检索结果填写。接入检查单：

- 能否增量、删除和按租户过滤。
- 能否拿到原文标识、位置和版本。
- 内容是否被用于训练，合同或文档如何写。
- 重建索引时线上读的是哪一个版本。

## 4.3.6 退出条件

- 每类知识有所有者、生效和失效规则。
- 会话、偏好、组织知识、本体候选分库存。
- 抽样回答能打开引用原文。
- 删除一条文档后，检索不再返回它的切片。
