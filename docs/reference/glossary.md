# 术语表

| 术语 | 在本文中的含义 |
| --- | --- |
| AI4D | 把模型、知识、工具和评测放进软件交付与运营的做法 |
| Scene | 业务流程和数据边界，用来约束 Agent 能进入的步骤和能读的数据 |
| 自主性等级 | 只读问答、建议、受控写入、高影响动作 |
| Coding Agent | 在仓库里生成或修改代码的助手。合并仍由人负责 |
| RAG | 先检索依据再生成。检索和生成分开评测 |
| Embedding | 把对象映射到向量以便按距离召回。距离近不等于事实为真 |
| 向量库 | 向量和过滤字段的索引。原文和事务不放在这里当唯一副本 |
| 本体 | 领域概念和关系的显式、形式化、可共享说明 |
| T-Box / A-Box | 概念与公理，以及具体事实 |
| SKOS | 术语和别名的组织方式。Concept 不自动等于 OWL 类 |
| SHACL | 检查数据或输出的形状 |
| L0–L5 | 本体介入深度：无、术语、结构、关系检索、推理与校验、治理演化 |
| Contract / Index / Guardrail / Memory | 本体的四种职责，可同时存在 |
| 能力问题 | 建模前写下、模型必须能回答的问题 |
| 控制面 | 身份、策略、评测、预算、审计和降级 |
| 执行面 | 模型、检索和受白名单限制的工具调用 |
| Trace | 把一次请求的模型版本、知识版本、检索和工具串起来的记录 |
