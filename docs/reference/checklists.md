# 清单

## 需求

- 用户、触发、现状、结果、错误成本、数据来源、允许动作、验收、非目标都有句子。
- 至少一条正例、一条无依据反例、一条越权反例。
- 模型补上的数字和角色已回指真实样本，或已删除。
- 已接受规格在版本库里，不在聊天记录里。

## 架构评审

- 业务、应用、AI 三张视图能对上同一次请求。
- ADR 写了决定、后果和放弃方案。
- 写工具有副作用等级、幂等键、超时和审计。
- 失败、降级和人工接管在状态里，不在 Prompt 里。
- 模型看不到生产凭证。

## Agent

- 已说明为什么不是固定工作流。
- 步数、预算和停止条件有测试。
- 工具 Schema 含错误类型。
- 完成以工具回执为准，不以模型自述为准。

## RAG 评测

- 改写、过滤、召回、重排、引用、拒答可以分开看失败。
- 过期文档不会和新版本同时作为现行依据。
- 越权样本在检索结果里就不出现。
- 引用位置属于本次召回的切片。

## 本体发布

- 能力问题有查询、推理或 SHACL 测试。
- OWL、SHACL 和应用规则的分工写明。
- 版本 IRI 和兼容性已记录。
- 新关系在候选区，未直接进入正式 T-Box。

## 发布和值班

- 兼容矩阵含代码、模型、Prompt、知识、索引、策略。
- 生产没有浮动模型别名。
- 值班知道如何关写工具，以及如何按矩阵回滚。
- 事故样本会进入评测集。
